---
name: tramuri-discovery
description: Find discovery gaps, assumptions and questions that require evidence.
---

## When to use
Identify missing context or evidence that could materially change a product
decision after initial framing.

## When not to use
Do not repeat discovery when the current run has adequate evidence or turn every
unknown into a question for the user.

## Inputs
Framing, project context, prior artifacts, available sources and decisions.

## Process
List gaps, assess impact and reversibility, check for existing evidence, then
choose a safe operational assumption or ask a concise question only if the
decision cannot proceed responsibly.

## Output contract
Return prioritized gaps with impact, evidence state, recommended next action and
any question that truly requires user input.

## Quality checklist
- [ ] Existing run and project context were checked first.
- [ ] Low-impact unknowns become labeled assumptions.
- [ ] Questions are limited to material unresolved decisions.
- [ ] No interview, research or market result is fabricated.
