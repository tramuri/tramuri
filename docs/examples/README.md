# Tramuri examples

End-to-end tutorials using fictional data, from installation through outcome review. With an
assistant integration, the primary path is to describe the goal in natural language; the
command-by-command sections are an optional terminal alternative. Product Engineer and FDE are
perspectives, not permission levels.

| Persona | English | Português (Brasil) |
| --- | --- | --- |
| Product Engineer | [Tutorial](product-engineer/README.md) | [Tutorial](product-engineer/README.pt-BR.md) |
| Forward Deployed Engineer | [Tutorial](fde/README.md) | [Tutorial](fde/README.pt-BR.md) |

The tutorials use features from Tramuri 0.5.0 onward. `uv tool install tramuri` installs the latest
published release, so check `tramuri --version` and continue only if it is 0.5.0 or newer. Codex
integration is optional; `tramuri install --help` lists platform choices supported by your release.
