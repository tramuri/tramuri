# Decision support

Use when a material decision blocks the currently authorized DEFINE step. Review the Mission and
accepted artifacts first. State the decision, evidence, alternatives, consequences, uncertainties,
and a recommendation when justified. Prefer a reversible, explicitly labeled hypothesis for low-risk
choices. Ask only when a choice changes product direction, creates material risk, or requires human
authorization. Route ordinary questions through `tramuri mission define question request`; the Core
persists a maximum of two. Do not bypass security, financial, privacy, or contract approvals when the
budget is exhausted. A declared answer source is attribution, not authentication.
