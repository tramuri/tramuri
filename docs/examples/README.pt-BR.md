# Exemplos do Tramuri

Tutoriais completos com dados fictícios, da instalação à revisão do resultado. Com a integração de
um assistente, o caminho principal é descrever o objetivo em linguagem natural; os comandos são uma
alternativa opcional para usar no terminal. Product Engineer e FDE são perspectivas, não níveis de
permissão.

| Persona | Português (Brasil) | English |
| --- | --- | --- |
| Product Engineer | [Tutorial](product-engineer/README.pt-BR.md) | [Tutorial](product-engineer/README.md) |
| Forward Deployed Engineer | [Tutorial](fde/README.pt-BR.md) | [Tutorial](fde/README.md) |

Os tutoriais usam recursos do Tramuri 0.5.0 em diante. `uv tool install tramuri` instala a versão
publicada mais recente; confira `tramuri --version` e continue somente se for 0.5.0 ou superior. A
integração com Codex é opcional; `tramuri install --help` mostra as plataformas disponíveis.
