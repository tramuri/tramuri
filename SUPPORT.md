# Support

For usage questions, bug reports, or feature requests, open an issue in the
[Tramuri repository](https://github.com/tramuri/tramuri/issues). Include the Tramuri version,
operating system, a minimal reproduction, and relevant command output. Remove credentials and
sensitive project data before sharing logs or examples.

Do not use public issues for security reports; follow [SECURITY.md](SECURITY.md) instead.

Tramuri is an early-stage open-source project maintained by a small team. Responses are best effort
and do not have a guaranteed service-level agreement.
